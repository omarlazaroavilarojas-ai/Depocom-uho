# Recepción en depósito

Se agregó la opción «Recepción en depósito» al menú y se conectó el componente PanelRecepcion.vue ya existente. No se modificó el backend ni las funciones de recepción.

Instalación: copia el contenido de este ZIP sobre tu carpeta frontend, conservando copia de seguridad, y reinicia Vite.

Prueba: entra a Recepción en depósito, selecciona una solicitud aprobada por Economía, consulta sus equipos y registra la recepción si tu usuario tiene permisos.
