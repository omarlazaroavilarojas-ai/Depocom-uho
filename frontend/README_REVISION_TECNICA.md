DepoCom UHO — Integración de Revisión Técnica

Se integra el panel ya existente en la opción Revisión técnica, mostrando solicitudes aprobadas por área y en revisión. Las acciones siguen las comprobaciones de rol y estado existentes. No modifica el backend ni las rutas de API.

Instalación: copia el contenido del ZIP en la carpeta frontend, conserva copia de seguridad, ejecuta npm install si es necesario y npm run dev. Comprueba la transición iniciar revisión, diagnóstico y aprobación técnica con usuarios autorizados.
