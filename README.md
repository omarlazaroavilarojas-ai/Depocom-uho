
# DepoCom UHO

Sistema de Gestión del Depósito de Equipos y Piezas de Cómputo.

## Institución
Universidad de Holguín, Cuba.

## Objetivo
Desarrollar una aplicación web para gestionar
las solicitudes de baja, recepción, despiece,
almacenamiento, reutilización y trazabilidad
de equipos y piezas informáticas.

## Tecnologías previstas
- Python
- Django
- Django REST Framework
- Vue.js 3
- PostgreSQL
- Docker Compose

## Estado del proyecto
En desarrollo.

## Instalación
Las instrucciones se añadirán durante
el desarrollo del sistema.
